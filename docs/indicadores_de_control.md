# Indicadores de control y estándares de desempeño

Para evaluar el cumplimiento de los objetivos del software de Buscando Huellas, se establecen los siguientes indicadores de control y estándares de desempeño, tomando como referencia las metas definidas en el TP2 y las actividades representadas en el modelo BPMN del TP4.

| Indicador de control | Estándar de desempeño |
|---|---|
| Tiempo de registro de una publicación | Cada publicación de búsqueda debe poder completarse en menos de 5 minutos. |
| Información obligatoria de las publicaciones | Cada publicación debe incluir al menos una fotografía y una descripción de la mascota. |
| Métodos de autenticación | El sistema debe contar con al menos 2 métodos de autenticación funcionales. |
| Actualización del estado de las búsquedas | El sistema debe registrar correctamente el estado correspondiente cuando el dueño confirma el hallazgo o cancela la búsqueda sin haber encontrado a su mascota. |
| Notificación de nuevos comentarios | El sistema debe generar una notificación al dueño cuando otro usuario realiza un comentario en su publicación. |

Los indicadores establecidos servirán como referencia para evaluar el cumplimiento de los objetivos y el funcionamiento del software durante su futura implementación.
